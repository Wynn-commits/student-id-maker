# IoT and AI-Based Camera Trap – Individual Monkey Recognition (Vue 3)
Proposal site + monitoring dashboard for Group 5, PFIT 03 (CPSU). Vue 3 + Vue Router + Vite.

    npm install
    npm run dev      # development
    npm run build    # production build in dist/ (hash routing, works on any static host)

Pages: Proposal (/), Sign in, Dashboard, Monkey Profiles, Sighting Review, Camera Traps, Users.
All dashboard values are sample data from Figures 8-11 (src/data.js). The back end (Node.js/Express + MySQL)
and Python recognition service described in the proposal are not part of this front end.
